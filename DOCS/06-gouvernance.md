# Northstar OS - Gouvernance

## Philosophie Open Source

Northstar OS est un projet open source.

Le code source du système doit être accessible publiquement afin de permettre :

- l'étude du fonctionnement interne ;
- l'apprentissage ;
- la contribution ;
- l'audit de sécurité ;
- la pérennité du projet.

## Transparence

Les composants principaux du système doivent être documentés.

Les décisions d'architecture importantes doivent être expliquées et archivées.

Les utilisateurs doivent pouvoir comprendre pourquoi une décision technique a été prise.

## Contributions

Les contributions externes sont encouragées.

Toute contribution doit respecter :

- les principes fondamentaux du projet ;
- l'architecture générale ;
- les standards de qualité définis par le projet.

## Sécurité

La transparence du code ne doit pas être considérée comme une faiblesse.

La sécurité doit reposer sur la robustesse de l'architecture et non sur le secret du code source.

## Pérennité

Northstar OS ne doit jamais dépendre d'une seule personne pour survivre.

La documentation doit permettre à d'autres développeurs de comprendre et maintenir le projet même en l'absence du créateur original.

## Communauté

La communauté est considérée comme une partie intégrante du projet.

Les utilisateurs sont encouragés à :

- signaler des problèmes ;
- proposer des améliorations ;
- développer des modules ;
- participer à la documentation.

## Vision

Construire un système d'exploitation ouvert, modulaire et durable, capable d'évoluer grâce à sa communauté.
