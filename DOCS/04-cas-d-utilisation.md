# Northstar OS - Cas d'Utilisation

## Cas 1 : Passionné d'informatique

L'utilisateur installe Northstar OS afin d'explorer son architecture et ses fonctionnalités.

Objectifs :

- personnaliser le système ;
- expérimenter avec les modules ;
- découvrir les mécanismes avancés ;
- contribuer au projet.

Modules possibles :

- Interface graphique ;
- Outils développeur ;
- Outils expérimentaux.

## Cas 2 : Développeur

L'utilisateur souhaite disposer d'un environnement de développement complet.

Objectifs :

- programmer ;
- compiler ;
- tester ;
- déployer.

Modules possibles :

- Profil Développement ;
- SDK Northstar ;
- Outils de virtualisation ;
- Conteneurs.

## Cas 3 : Joueur

L'utilisateur souhaite maximiser les performances et la compatibilité des jeux.

Objectifs :

- exécuter des jeux récents ;
- réduire la consommation système ;
- simplifier la configuration.

Modules possibles :

- Profil Gaming
- Compatibilité Windows ;
- Pilotes graphiques ;
- Services multimédias.

## Cas 4 : Serveur

L'utilisateur souhaite déployer un système minimal sans interface graphique.

Objectifs :

- héberger des services ;
- administrer à distance ;
- réduire la consommation de ressources.

Modules possibles :

- Core System ;
- Réseau ;
- SSH ;
- Conteneurs.

## Cas 5 : NAS

L'utilisateur souhaite transformer une machine en serveur de stockage.

Objectifs :

- partager des fichiers ;
- gérer les sauvegardes ;
- centraliser les données.

Modules possibles :

- Services réseau ;
- Gestionnaire de stockage ;
- Interface d'administration.

## Cas 6 : Station de Travail

L'utilisateur utilise Northstar OS pour des tâches professionnelles.

Objectifs :

- bureautique ;
- création de contenu ;
- productivité.

Modules possibles :

- Profil Bureautique ;
- Suite logicielle ;
- Synchronisation cloud.

## Objectif Global

Tous ces usages doivent être pris en charge par une seule base système.

L'utilisateur choisit ses modules.

Northstar OS s'adapte
